# Use automatic repair and document quarantine

Video Harness does not place records into a human review queue during corpus generation. Normal compilation failures enter bounded Targeted Reprocessing, complete documents receive a Sequence Audit, and unresolved evidence quarantines the whole Behavior Document from default Reader and training paths. Human inspection remains an offline sampled evaluation of Harness quality, not a dependency of the production data pipeline.
